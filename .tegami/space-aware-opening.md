# Resolve automatic placement and focus in one open request

Add a workbench-level opening policy with native placement admission, fixed-location reuse and
explicit-destination precedence. Inspection can choose a same-pane activated detail when space
is insufficient, while preserving preview, source lifetime and asynchronous focus protection.

Route metadata and mounted controllers can declare minimum and preferred reading sizes. Dynamic
route declarations resolve before first render; shared content components can update mounted
needs without resizing existing native panes. Export the route-size resolver and the existing
native split-direction query for host policies.
