# Complete document entrances and bounded desktop coordination

Add explicit preserve-location reuse, a workspace preview lifetime with keep, navigation decision
context and optional native topology constraints with synchronous Action eligibility. Lazy restored
documents participate in identity reuse without eager loading. New preview content receives a new
Router/document id; dirty content is retained and native pin is distinct from keep.

Explicit activation reveals maximized target groups and restores first-open focus after lifecycle
registration without stealing later user focus. Duplicate live lifecycle registration is rejected
instead of silently replacing an owner and losing cleanup.

Validate these paths through the public tarball consumer at desktop baseline and compact desktop
sizes, including actual native mouse docking. Existing applications still require migration.
