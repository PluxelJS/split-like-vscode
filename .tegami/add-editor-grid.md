## Add recursive editor grids

Add a validated, serializable editor-grid model with mixed horizontal and vertical splits. Workbench
editor groups can now be rearranged, equalized, and maximized while preserving the existing flat
horizontal default and keeping application content lifecycle under consumer ownership.
