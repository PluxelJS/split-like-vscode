# 浏览器验收入口

运行 `pnpm test:browser`。当前入口是 `scripts/check-demo-browser.mjs`：构建正式 demo，再用官方 Chromium 在 1440×900 和 900×768 两种视口执行同一组实际交互。独立安装验收 `pnpm test:package` 使用相同 demo 源码及下面三个检查模块，不维护第二套假应用或旧 API 适配器。

| 共享检查                               | 保留的实际浏览器保护                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scripts/check-public-api-browser.mjs` | 文档链接真实拖放至标签索引和分屏；原生 F6 焦点；保存 A 期间修改 B；保存失败和取消弹窗；后置原生 blocker 的暂停/释放；工具自定义菜单及关闭后的弹窗焦点；工具实际 Border 拖放保留输入和 DOM                                                                                                                                                                                           |
| `scripts/check-demo-interactions.mjs`  | SplitView 鼠标/键盘尺寸及折叠保活；原生分组、折叠、移动、单标签组、手工标题与固定标签；浏览器前进/后退和 v2 快照重载                                                                                                                                                                                                                                                                |
| `scripts/check-workbench-browser.mjs`  | 慢打开丢失前台资格；初始焦点与最大化兄弟显露；文档组 Border 往返保留 DOM、滚动、草稿和资源；不可关闭工具保护整个混合组；审批期间成员变化使整批关闭失效；原生慢导航取代及加载中关闭结算；重复关闭共享批准和保存依据；多文档 dirty batch 暂停/拒绝/释放；连续浏览器后退拒绝、显式打开取消待定遍历；loader/render 错误隔离；redirect 的复用与独立内容身份；最终原生 history 和资源清理 |

旧 Playwright specs 的有效场景已迁入这些模块。旧命令注册框架、`worksplitDemo` 调试 API、按 URL 身份冲突拒绝原生导航，以及“新路由抹掉手工标题”的断言被新契约取代；不保留兼容执行路径。更细的原生 Actions、恢复格式、leave token、并发批次和生命周期组合仍由库定向测试保护，但这些测试不替代上表的浏览器交互。

每次运行的结果、截图和失败 trace 属于忽略的 `test-results/` 或 `.artifacts/`；当前已执行范围与尚未通过项以 [验收说明](../../../docs/proposals/README.md) 为准。这个索引描述验收入口和保护归属，不宣称尚未执行的验收已经通过。
