# Worksplit 整体重构实施说明

面向接手实施的 GPT 6.1 sol 或其他 coding agent。状态：**2026-11-03，待实施**。
本次文档交付不包含运行代码重构；不要把提案中的目标 API 当作现在已经存在。

## 任务

依据[设计原则](../design-principles.md)与[完整提案](worksplit-redesign.md)，
对 Worksplit 做一次贯穿公共 API、内容寿命、原生接纳、菜单、历史、包与消费者的完整重构。
目标是下游直接使用 FlexLayout/TanStack 原生能力，同时获得完整文档协调和默认体验。
用户已明确选择破坏性替换：外部应用会迁移，**不留旧 API 或旧快照兼容**。

不要只完成命名替换、移动文件、把 4 改成配置或抽走菜单。
也不要设计第二套布局、路由、命令平台、菜单语言、插件系统或业务保存协议。
按依赖关系连续完成同一套架构，不再把设计拆成多轮等待用户重新决定。

## 容易做错的地方

- `hasUnsavedChanges` 是事实，false 不能跳过决定；pending write 是否能离开由应用判断。
- allow 绑定应用实际审核/保存的 token。不要返回“弹窗结束时最新 token”，也不要一概要求等于保存前 token。
- 全批先决定再删除；这不承诺回滚应用保存，也不承诺原生 Model observer 抛错后的事务原子性。
- 读 hook 不登记 owner。controller 不可用时不能将以前受保护的存活内容当成 clean。
- closeWorkspace 不是“关掉所有可关闭标签”：它覆盖 pin/不可关内容及可选 workspaceLeave；dispose 则是强制终止。
- `getTabNodes()` 的可见成员不能代替折叠组的完整关闭范围；分组是原生 TabGroup，窗格是 TabSet。
- 默认菜单属于库的正式交付；财务文案、HeroUI 弹窗、2×2、35% 和凭证选窗属于应用。
- 完整 Model.toJson() 会触发原生 save listener，不能用于查询、disabled 或高频候选预检。
- route loader、放置 resolver、资源 effect 都有副作用/调用次数边界；不能每试一个方向重跑 loader。
- source、目标节点、controller 与内容 ID 的实际实例不同；旧 async 结果不能命中同 ID 的新对象。
- “已接纳”“DOM 已绘制”“保存回调返回”“业务回执确认”“资源释放完毕”各有完成点。
- 原生浮动/多窗口、任意 Model 替换、undo 复活资源不是因为 FlexLayout 支持就自动获得集成保证。
- pnpm patch 不会随 tarball 自动施加到宿主 peer；独立消费者必须使用匹配的实际原生制品。
- 历史证据和新设计的验收分开；不能通过改 mock/删测试把真实回归变成绿色。

这些提醒不是另一个契约清单；有疑问返回提案的对应章节、理由和验收编号。

## 实施与验证方式

先让目标公开类型和必要失败用例约束实施，再沿真实操作路径重构。
分工应围绕不变量，避免把巨大 integration.ts 换成一串没有明确所有者的小 controller。
控制源头分别是内容实例、离开协调、原生接纳、活动/焦点和浏览器历史；菜单/链接只接它们的公开操作。

完成一段行为后运行受影响测试与类型检查；稳定后运行仓库根 verify。
保留缓存，任务串行，不因只有文案更新重复跑全量。
随后验证 demo 浏览器和独立打包安装的浏览器消费者；实际应用必须证明加载的是新源码/新制品，不能只看类型通过。
Pluxel 宿主的运行修改按其本地 skill 与 dev-console HMR batch 流程执行。

对照[提案验收矩阵](worksplit-redesign.md#行为验收矩阵)逐项登记证据，保留以下差异：

- 源码单元/类型测试与真实 Router/Model 集成；
- workspace development 条件与独立 tarball/dist 消费；
- JSDOM 与真实键鼠/拖拽/焦点；
- 可重复微基准与真实宿主运行；
- 已迁移源码与已启动并验证的新版本。

性能比较使用相同行为、样本和环境，记录序列化、Router/订阅/挂载数量与耗时。
不要用“文件更少”“依赖名更少”代替结果证明。缺少环境就如实写未执行和影响，不通过放宽契约获得完成状态。

交付说明列出：实际行为改变、关键保护与结果、消费者迁移范围、测试/浏览器/制品/性能证据、未完成的外部迁移及限制、提交位置。
只有达到完整目标才标记实现完成；无关业务核心、主线合并或包发布仍遵守当次任务的授权与仓库约定。
